# 怀旧剧场直播 IPTV

一个 Android TV「伪直播」电视应用：**用 1970 年 1 月 1 日 00:00:00 作为起点的地球时钟，把 82 部国产经典电视剧变成 82 个永不间断的直播频道。**

打开就是「正在播出」，没有进度条可以拖，没有下一集可以点 —— 就像九十年代打开电视机那样。

---

## 核心原理

### 数据源

节目单来自一份 JSON：

```json
{
  "https://.../视频/电视剧/三国演义/01桃园三结义.mkv": 2624448,
  "https://.../视频/电视剧/乔家大院/01.mp4": 2758400
}
```

- **Key**：视频地址，路径**倒数第二段 = 电视剧名字**
- **Value**：视频时长，单位**毫秒**

全库共 **4098 集 / 82 部剧**。

### 时间轴算法（各剧独立轮回）

对每一部剧：

1. 把它的所有集按**文件名自然序**排序（`02` 排在 `10` 前面，而不是字典序）
2. 累加每集时长，得到整部剧的**总时长 T**
3. 取当前时刻距 1970-01-01 00:00:00 UTC 的毫秒数 **E**
4. 该剧当前偏移 `offset = E mod T`
5. 在累加时间轴上**二分查找**，定位到具体是第几集、集内第几秒

```
三国演义（84 集，总时长 T = 2天9小时26分）
  ├─ 01桃园三结义  0 ────────── 43:44
  ├─ 02十常侍乱政  43:44 ────── 1:24:44
  ├─ ...
  └─ 84xxx        ───────────── T

E mod T 落在哪里，电视上就播哪里
```

**因为所有剧共用同一个 1970 起点，任意时刻每部剧都有唯一确定的位置，切换频道时不会出现跳变。**

边界验证：

| 时刻 (UTC) | 《三国演义》播放位置 |
|---|---|
| 1970-01-01 00:00:00 | 第 1 集 00:00 / 43:44 |
| 1970-01-01 00:00:01 | 第 1 集 00:01 / 43:44 |
| 1970-01-02 00:00:00 | 第 35 集 36:35 / 40:28 |
| 2000-01-01 00:00:00 | 第 72 集 06:12 / 43:10 |

### 直播感如何营造

| 手法 | 实现 |
|---|---|
| 秒级跳转 | 进频道后 `seekTo(offset)` 并起播，从头就来 |
| 不可快进 | 不提供进度条拖动，只有只读进度展示 |
| 集数自动流转 | 播完自动跳到该剧「此刻」该在的那一集 |
| 实时时钟 | 每秒刷新系统时间与位置 |
| 直播标识 | 左上角 `● LIVE` 红标 + 底部进度 |
| 记忆频道 | `SharedPreferences` 记录上次观看的剧，下次直接进入 |

## 操作方式（遥控器）

| 按键 | 作用 |
|---|---|
| **上 / 下** | 在电视剧列表中移动焦点 |
| **确认 / OK** | 切换到选中的电视剧 |
| **菜单** | 刷新节目单 |
| **左** | 把焦点拉回左侧列表 |

---

## 技术栈

| 组件 | 选型 |
|---|---|
| 播放内核 | **AndroidX Media3 ExoPlayer 1.3.1** |
| 网络层 | OkHttp + OkHttpDataSource（支持边下边播） |
| 界面 | 纯手写 RecyclerView + 自定义焦点管理 |
| 最低版本 | **Android 5.0 (API 21)** |
| 目标版本 | Android 14 (API 34) |
| 构建 | Gradle 8.7 + AGP 8.2.2 + JDK 17 |

支持容器/编码：**MKV、MP4、TS**，H.264 / H.265。

## 构建

### 云端（推荐）

推送到 `main` 分支即自动构建，产物在 **Releases** 页面。

```
Actions → Build APK → 下载 IPTV-release.apk
```

### 本地

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleRelease
# 产物: app/build/outputs/apk/release/app-release.apk
```

### 安装到电视

```bash
adb connect 192.168.1.x:5555
adb install -r app-release.apk
```

或拷贝到 U 盘，在电视上允许「未知来源」后安装。

## 验证算法

不装 Android 也能验证时间轴是否正确：

```bash
python3 scripts/verify_timeline.py durations.json
```

输出当前时刻每部剧的播放位置，并生成 `schedule_snapshot.json` 全库快照。

## 数据源容错

节目单按顺序尝试多个源，任一成功即用：

1. `https://www.totootao.top/alist/...` （原始 AList，实时）
2. `https://ghproxy.totootao.top/.../gh-data/durations.json` （GitHub 镜像，30 分钟新鲜度）

首次启动即写入本地缓存，**断网也能正常进入并播放上次的频道**。
